# MCP Cleanup
---
This is a command line tool that implements the ForgeGradle2's [PostDeocmpile](https://github.com/MinecraftForge/ForgeGradle/blob/FG_2.3/src/main/java/net/minecraftforge/gradle/tasks/PostDecompileTask.java) tasks.

It is meant to be used as a command line tool for MCPConfig or Mavenizer.

Usage:
`java -jar mcpcleanup.jar --input input.jar --output output.jar`
